方式一：☁️ Cloudflare Pages 绑定 GitHub 自动更新（最省心）正在检测本机 GitHub 连接…

先把最新纯播放版一键推到你的 GitHub 仓库，再在 Cloudflare Pages 绑定该仓库即可生成 *.pages.dev 地址（国内访问更快；以后改完再点一次按钮就会自动同步更新线上地址）。

推送版本选择
☁️ 打开 Cloudflare 控制台 ▶ 本地试玩纯享版
  1. 打开 Cloudflare 控制台 → Workers & Pages → Create → 切到 Pages → Connect to Git，选仓库 birthday-gift-26（Build command 与 Output directory 均留空，点 Save and Deploy）。
  2. 若选「复刻原站完整版」：在 Cloudflare Storage & Databases → KV 新建一个免费命名空间，再回到 Pages 项目 Settings → Bindings → Add → KV namespace，Variable name 填 SITES 并保存，重新部署后即可在第 9 关点「生成地址」秒出 /?s=随机码！
  3. 若选「纯享直达版」：无需绑定 KV，部署好后主页地址本身就是纯享播放版，直接发给朋友即可。

方式二：直接下载压缩包上传 Cloudflare Pages（Direct Upload，不连 Git）

不想绑定 GitHub 时，在 Cloudflare 控制台选 Workers & Pages → Create → Pages → Direct Upload，直接拖入下方 .zip 压缩包（或本地 dist-github/ 文件夹，单文件最大 5.1 MB，远低于 Cloudflare 25 MB 限制）即可秒出网址！
